# Stem Studio backend as ComfyUI workflows

Stem Studio is a desktop front end. Everything it does to your audio runs as ordinary ComfyUI graphs built from the `StemStudio` custom nodes in `comfy_nodes/StemStudio`. These workflows give you the same backend without the app, so you can run, fork and chain it inside plain ComfyUI.

| Workflow | What it does | Models |
|---|---|---|
| `Stem-Studio_01_Separate-Dialogue-Music-Effects` | Three stems from any audio or video soundtrack | MRX (default, MIT), BandIt v2, SFC (non-commercial) |
| `Stem-Studio_02_Pull-A-Named-Sound-USS` | Pull any AudioSet sound (footsteps, door, rain...) plus the remainder | USS + PANNs (Apache 2.0, CC BY 4.0) |
| `Stem-Studio_03_Describe-A-Sound-SAM-Audio` | Describe a sound in English and pull it out (experimental) | SAM Audio (gated on Hugging Face) |
| `Stem-Studio_04_Guide-By-Reference-GuideSep` | Pull an instrument by humming or playing a reference (experimental) | GuideSep v1 (MIT) |
| `Stem-Studio_05_Stems-Then-Footsteps` | Stems first, then footsteps from the effects stem | MRX + USS |
| `Stem-Studio_06_Paint-A-Sound-Stable-Audio-3` | The brush: a prompt becomes a sound placed at a time on the source's timeline | Stable Audio 3 Small-SFX (Stability AI Community License) |

Open a `.json` from this folder with **Workflow > Open** (graph format). The `api/` folder holds the same graphs in API format, exactly what the app submits, for scripts and the Comfy SDK.

## Setup

1. Run the Stem Studio setup once. It copies the nodes into `ComfyUI/custom_nodes/StemStudio`, downloads the pinned model files into `ComfyUI/models/audio_separation` and writes `runtime.json`. Restart ComfyUI afterwards.
   - Doing it by hand: copy `comfy_nodes/StemStudio`, put the model packs from `setup/models.json` under `models/audio_separation`, and create `runtime.json` next to the nodes with `{"checkpoint": "<models>/audio_separation/sfc-locoformer-dnr/model.pth", "model_root": "<models>/audio_separation"}`.
2. SAM Audio and GuideSep need a private Python runtime and their weights. Prepare them once from the app (SAM needs your own Hugging Face approval and token, GuideSep needs no account).
3. Put your file in `ComfyUI/input`, select it in **Load Audio** and queue. Video files work as inputs. Results are FLAC files in `ComfyUI/output/StemStudio`.

## Notes

- The save nodes use `SaveAudio`, which current ComfyUI marks as deprecated but still runs; swap in `SaveAudioAdvanced` if you prefer.
- All processing is local. No partner nodes and no API calls.
- The graph files are generated by `node scripts/make-workflows.mjs` from the same code the app uses (`electron/separation.mjs`), and `npm test` checks them against the node definitions. They were not opened in the ComfyUI interface by the author, so report any layout or widget issue.
