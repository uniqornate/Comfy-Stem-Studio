# Architecture

## 0.11.0 non-destructive clips and model variants

clip-edits.mjs validates sorted clip/gain ranges, implements split/trim and gain replacement preserving outside regions, and derives audible scheduling segments. Clip source offsets equal timeline time: trimming produces silence, never ripple or time-stretch. Regions overwrite intersecting gain automation rather than stacking unknowingly. Per-take edits are serialized beside the existing mix and groups, validated in main and restored independently of decoded buffers. WebAudio schedules each active source segment with a separate fixed regional gain node feeding the track's mixer gain. Video remains the time authority. A split without trimming leaves complete sample coverage. Memory limits and full-channel FLAC source files remain unchanged.

Comfy StemStudioEditAudio applies a full-length float envelope with clip masks and regional dB gain. This node runs before detail cropping/padding and inside the AudioRenderer SDK export graph; no desktop Python/encoder process renders audio. Edited export files are native SaveAudio outputs resolved locally for configured Comfy or downloaded only for compatibility deployments. Video export receives the baked FLAC and retains the existing native SaveVideo/packet-copy adapter. Original active media cannot be an export overwrite destination. Individual/batch stems include clip/gain edits but retain prior independence from global mute/solo/level mixer controls. Track-mode video still ignores those mixer controls; mix-mode video honors them. Existing AudioRenderer cancellation cancels only its own submitted SDK job. Source/model jobs are not cancelled on an unrelated edit operation.

Wave height preview bypasses the channel-list React tree while dragging, using RAF CSS updates and local dial state, then commits once. Floating preview edge grips preserve the existing video element and persist its size. Selection gain hover uses lane-local DOM class updates and appears only within the selected time interval. Context extraction falls back to full timeline duration without selection. Keyboard split is suppressed inside modals/text inputs. Edit limits:256 clips/512 gain regions; Reset channel edits is provided, no Undo/time-stretch/crossfade implementation. Real gesture performance, audio boundaries, gain clipping behavior and video parity remain user acceptance.

SAM variants are an allowlisted small-tv/large-tv optional Comfy input. Preparation selects the corresponding official repository/local model folder, retains one private package runtime and reuses encoder cache; markers store the cache path so Comfy's isolated worker uses it. Large is gated by updated node capability. HF tokens remain preparation-only; token settings and selected-model access links are explicit. No automatic switch to Small on Large inference failure. PromptSep is visibly unavailable: its repo only has README; its project-page Code Base link points at the distinct GuideSep music/mimicry model. No verified PromptSep-specific checkpoint/inference was located and no fake adapter is shipped.


## 0.10.0 native media and project sessions

Projects serializes manifest/index mutations, keeps a two-second renderer autosave and requests a final snapshot before normal window close. Each manifest is written through a temporary file and previous-file backup. Completed main-process results are merged before saving even if the renderer has not polled them. Recovery re-registers output handles and fresh opaque app-media URLs; no stale protocol URLs are used as durable media identities. Missing references remain in the manifest. In-flight model work is marked interrupted after restart, never resubmitted. Abrupt renderer/process termination restores the latest completed save, not unsaved last-millisecond edits.

For configured local ComfyUI, source import copies to input/StemStudio/<project-id>/<uuid>.<ext>. Project JSON is a sidecar in output/StemStudio/<project-id>; SaveAudio filename_prefix scopes each processing run below that folder. USS All accepts an optional validated prefix and uses the built-in AudioSaveHelper. Official SDK job outputs resolve exact native filenames or the known run folder plus basename, with canonical-path containment checks. The primary file remains Comfy's saved FLAC; projects retain relative output references and optional SDK asset/job IDs instead of duplicating it. All processing continues through official SDK submit. Native video saving remains the existing SaveVideo workflow. Standard directories are required; custom CLI input/output overrides are not automatically discovered. Configured-native output lookup failure is explicit, never silently downloaded elsewhere. Legacy/no-installation projects retain managed assets for compatibility.

Project manifests retain per-take mixer/groups, waveform height and zoom, scroll, selected take, transport position/range/loop, layout scale/split/expanded state/floating position and last operation/detail guidance. The main allowlist excludes connection profiles/tokens. Source relink preserves audio/takes and imports a replacement into the same native input project. Save as creates a separate workspace identity and shares native references; legacy managed assets are copied. Source/FLAC file references and UI data are validated; traversal is rejected. Recent projects are bounded to20. Compare takes remain bounded to12 and total persisted channels to8192. The project sidecar is app-specific session metadata, not a native Comfy graph file; native media and processing nodes remain the source of results.


## 0.9.0 SAM multimodal guidance

SAMGuidanceEditor keeps free description, absolute positive/negative examples, automatic span prediction and manual visual boxes in the same picker. normalizeGuidance validates finite bounds, contradictory anchors, box/time limits and converts absolute times once to crop-local seconds. Picture only sends an empty SAM description and disables text span prediction. Normal card labels remain the fallback query. The renderer's global Space handler explicitly lets spaces through only in the SAM description textarea; Ctrl+Enter uses the same validated modal submission.

Separation graphs include guidance_json and optionally native LoadVideo at node6. Electron resolves the approved original app-media token independently from the selected parent stem and overwrites any renderer path field. Both assets upload through the official SDK. Prompt capabilities are discovered by optional SAM node inputs and targeted LoadVideo inventory. The shared pure module ships in app.asar/src for the main-process import as well as the frontend bundle.

Comfy validates crop-relative guidance again before invoking the isolated worker. It streams the original video through PyAV at four sample frames per second, at most121 frames/256px long edge for a30s selection. PTS uses the video stream origin and processing offset; nearest samples and final-frame display duration cover EOF. Right-angle display rotation is applied. Normalized boxes interpolate linearly by time; only pixels inside each box remain, with black outside. These uint8 tensors pass directly to SAM's masked_videos input and are temporally aligned to the audio features by its processor. No external encoder, generated image asset, SAM3 segmentation or automatic object tracker is involved.

Worker retains the vision encoder only for visual cues and retains the span predictor only for automatic span mode. Visual encoder batches use two frames. It forwards explicit anchor lists to the official processor and uses a single candidate. Model quality, CUDA memory, real video orientation/seek behavior and actual model installation remain user acceptance. Full construction during existing preparation already includes the upstream visual/span modules, so no additional model is introduced by these controls. Visual selections longer than30s are refused before upload; audio-only use retains its existing path. The box editor is muted and never changes the shared main video transport.


## 0.8.0 timeline-local detail architecture

Channel context actions carry source stem ID, current root take ID and a finite selected range. Main resolves the source token and requires a matching owned cached parent path. The official SDK graph crops AUDIO with StemStudioAudioRange before USS/SAM. Normal target/remainder are padded through StemStudioRestoreRange; USS All performs the same padding before native FLAC output. Downloaded child IDs carry parent metadata; completion appends to the owning take instead of replacing the parent take. Distinct child download names avoid repeated-label collisions. Renderer groups recursively by parent, inherits root colors, collapses visual descendants without deleting audio, preserves existing mix state and initializes new children muted. Buffers are reused when adding channels; the existing 768 MiB preview guard remains. Collapsing does not mute or remove exports.

USS All keeps normalized low-resolution waveform fingerprints and suppresses absolute cosine similarity >=0.995 plus nearly silent fingerprints. This is a heuristic for obvious duplicate estimates, not semantic verification, mutually exclusive demixing or a precision guarantee. Detection uses existing per-class Auto calibration.

Shift release commits a valid selection into locked shared playback; cancel/empty selection does not auto-play. Existing unlock/clear remain. Timeline tools occupy grouped instrument banks. Expanded workspace uses display:contents for its upper grid, hides the source controls, and fixes the same mounted video section as a draggable borderless preview. A short drag threshold distinguishes click playback from dragging; pointer capture keeps dragging outside the picture.

SAMManager runs only after explicit in-dialog download/license consent and a session read token. It reuses the managed uv bootstrap but creates its own Python3.12 environment with matched Torch2.11/CUDA12.8, TorchVision0.26, TorchAudio2.11 and TorchCodec0.15. Upstream SAM, DACVAE, PE, ImageBind and CLAP source commits are pinned; auxiliary dependencies resolve under explicit CUDA/transformers constraints. No package changes occur in ComfyUI Python. Secondary HF/Torch caches live alongside the native model pack. Preparation downloads the official gated small-tv snapshot at its resolved immutable revision, loads processor/model on CPU, then repeats offline before writing a marker. Tokens use environment only, are redacted from output and are not stored. Preparation is cancellable and stops on app quit. No real preparation has been run by the agent.

The lightweight Comfy SAM node releases Comfy-owned models, writes a temporary floating-point WAV with soundfile, launches its isolated worker without a console, checks interruption, and loads target/remainder FLAC back to AUDIO. All execution remains inside the submitted Comfy workflow. Worker input is tensor audio rather than an external decoder; no external ffmpeg executable is invoked. Text-only one-candidate inference drops unused visual/ranker/span modules before moving the model to the selected CUDA device. Full CPU construction still caches upstream encoder dependencies. VRAM/quality/Windows dependency support are user acceptance, not a measured capability. External model links are an exact three-URL allowlist in the desktop window handler.


## 0.7.1 branding, console policy and resource monitor

Both QuietProcess and setup's PowerShell launcher now use CreateNoWindow=true. This supersedes the hidden-console allocation described below, which a user reported still left a persistent console tied to proxy lifetime. Job Object ownership, redirected logs and app-owned shutdown remain. No existing process is closed by this change.

The resource IPC validates the caller and normalizes the selected Comfy endpoint. It reads system_stats and the custom read-only /stemstudio/temperatures endpoint concurrently with two-second request timeouts. Renderer polls serially every three seconds and discards old endpoint responses. RAM/VRAM use Comfy's own free/total semantics, including its allocator accounting. Optional NVML identifies the same primary Torch GPU by UUID, or uses the only physical GPU if UUID is absent; ambiguous multi-GPU readings are omitted. CPU uses supported psutil CPU thermal groups, commonly unavailable on Windows. Neither monitoring dependencies nor subprocesses are introduced; missing sensors show n/a and old integrations retain memory readings. Source endpoint and full memory values remain in tooltips.

Renderer localStorage stores sanitized model/action/USS target/Auto/manual threshold preferences. Fresh defaults are SFC and USS All. This restores controls only, never source media, running inference, takes or mixer state. Supplied logo.svg is copied byte-for-byte and its vector paths are reused in WPF. The far-left branding block places Comfy before Stem Studio typography without a waveform icon.

## 0.6.2 process visibility and setup completion (historical)

The shared `setup/quiet-process.mjs` ships both in app.asar and resources/setup, so standalone setup and desktop imports resolve independently. A compiled GUI helper creates hidden console children, forwards original arguments and logs, and owns their Windows Job Object. Stopping its host closes only that owned process tree. Proxy preparation/start, engine launch and process-owner queries use the helper when configured; direct hidden spawn remains the development fallback. The bootstrap PowerShell host also starts with a hidden console. Descendants that explicitly open their own windows may still need separate handling. Live visibility and process cleanup are user acceptance items.

Successful Finish records launch intent, closes setup and starts the installed GUI with its installation directory and without ELECTRON_RUN_AS_NODE. Cancellation, failed preparation and titlebar close never record that intent. The helper is compiled before packaging; no compiler is required on the user's machine.

Comfy logo SVGs are original supplied bytes, with filenames/hashes in src/assets/comfy/provenance.json and a separate notice. Setup uses matching WPF DrawingImage geometry and colors without rasterization. Geometry and XML are parsed statically without creating a window. HTML logos follow the existing page zoom. The application executable icon remains Stem Studio's existing icon.

Decision: separate Electron desktop app, selected by the user on 2026-10-16. Working name: Stem Studio.

- Sandboxed preload exposes only named operations. Electron validates the invoking frame.
- Main process owns dialogs, persistent connection settings, approved media access and the official Comfy SDK.
- Custom app-media protocol exposes the selected source and cached stem files through opaque tokens.
- ComfyUI remains an external user-selected engine. Unified setup selects it first, installs the app-owned custom node and checkpoint configuration and, with its displayed checkbox approved, starts/restarts only a matching known local engine after queue-idle/process-identity checks. The desktop app does not restart engines. ComfyUI Python packages are not modified. Manual Install integration is a repair fallback with progress/result feedback.
- Comfy API Proxy supplies API v2 for SDK source uploads, workflow submission, job-specific cancellation, polling and output retrieval. electron/separation.mjs owns this lifecycle; readiness requires LoadAudio/StemStudioSeparate/SaveAudio, not just proxy health. It downloads pinned-hash uv, creates a managed Python 3.12 virtual environment in userData and installs the pinned official proxy package. Narrow IPC exposes only start(profile), status and stop; it never accepts arbitrary commands from the renderer. Runtime process arguments use shell:false, windowsHide:true, Python isolated mode, and explicit loopback bind. Initial download and child setup are cancellable. Only the tracked app-owned child is stopped; externally managed services are reused or reported as conflicts. A saved boolean startup preference opts into starting the managed proxy at app launch.

The host owns navigation, initial ComfyUI selection, native model placement, combined license/change consent, optional automatic engine control and application/model/service preparation state. The bootstrapper is compiled by build/package-setup.ps1 after electron-builder completes. No installer/app is launched during this build.

## 0.4.0 update (supersedes previous future-feature statements)

BandIt v2 and MRX are now optional installed three-stem engines selected through the StemStudioSeparate model input. USS/PANNs class-target extraction is implemented in StemStudioExtract with target/remainder outputs and a separate SDK graph. Sources and metadata are pinned in the model manifest and node NOTICE. Model files remain under native audio_separation subfolders, verified/reused on reinstall. Existing Comfy torch/torchaudio/numpy/einops/librosa are used, with relative vendored torchlibrosa/PANNs definitions instead of installing research stacks.

The frontend now renders actual decoded PCM peak waveforms in multitrack lanes. A shared Web Audio clock schedules all tracks at the same future time and offset; gain nodes implement mute/solo/level. Common transport, seek, zoom and one playhead per aligned lane replace independent browser audio widgets. App-media fetch is explicitly permitted by CSP, the custom protocol supports CORS, and only opaque selected/cached media tokens resolve to files. No arbitrary file path IPC or network fetch is exposed. A decoded-buffer size guard limits preview memory; downloads retain source bytes.

Successful SDK results have run IDs and are retained as selectable takes for the current source. Exports select an explicit take's opaque stem IDs, so a subsequent failed job does not remove earlier exports. New source selection resets the session and media token map. Timeline mixing is preview-only; the original video is independent and take switching starts playback from the beginning. Runtime/device tests remain user-owned.

## 0.4.1 download implementation

setup/Transfer.cs now includes ParallelModelDownload, driven by the existing download runspace for every file at least32MiB. It uses four native HttpClient range requests concurrently, fixed8MiB chunks, per-source connection limits, progress counters and bounded recovery, with no PowerShell callbacks in each network read. Legacy contiguous partials are retained; hash-bound exact start/end chunk paths retain both complete and partially written ranges. Size/range checks precede assembly; complete file hashes precede finalization/chunk cleanup. Existing exclusive .part.lock continues to prevent competing installers. Server HTTP200 on bounded-range requests signals sequential fallback without appending full responses to chunks. Cancellation joins native tasks before releasing the writer lock. Network byte counters exclude reused prefix/chunk data. Source rotation only uses configured URLs whose final bytes must satisfy the same model hashes.

## 0.5.0 transport and adaptive detection

src/media-transport.mjs replaces the independent waveform clock with video presentation time as transport authority. AudioContext sources use a shared timestamp/offset; seeking, stalls, rate changes and drift above 80 ms reschedule them. Original/Stems routing mutes the unused source. No rendered remux or frame-accurate parity claim is made. Decoded PCM waveforms are cached as SVG paths, with a 768 MiB preview guard. Per-lane clipping and bounded playhead positioning prevent end-of-playback horizontal overflow; intentional zoom scroll stays inside the timeline. A capture-phase shortcut listener handles Space regardless of focused control and Ctrl+Enter for the selected operation (0.5.1: default stems; focus/pointer interaction selects stems or USS; modal settings block extraction).

Auto threshold is optional on both USS nodes. The frontend discovers support from their optional input contracts and sends auto_threshold only when enabled. Old manual graphs remain compatible. auto_threshold.py contains a pure, offline-testable calibration heuristic: evidence >= min(0.30, max(0.08, median + 3 MAD)); extraction cutoff max(0.025, min(0.30, peak/2, median + 2 MAD)). Each class is calibrated separately across existing 2 s, 1 s hop classifier windows, including padded edges. Continuous high-confidence classes are retained; isolated events have no minimum-duration gate. There is no amplitude-based or sample-accurate short-event detection. Auto thresholds are printed in the ComfyUI log; manual threshold remains available. Score caching avoids a second classifier pass while extracting classes serially. Real precision/recall and listening acceptance are user-owned.


## 0.6.0 media service, display scale and video export

media-response.mjs owns byte-range parsing and streams fs.createReadStream via Readable.toWeb; registered app-media tokens remain the only file capability, and Range/HEAD metadata is explicitly returned with CORS. These responses are covered by real byte fixture reads without an actual video decoder. Timeline pointer capture supports ruler/lane scrub with clamped clientX/DOMRect coordinates.

layout:zoom validates a0.6..1.5 factor and sets webContents zoom; renderer remembers the factor. This scales HTML modals consistently; native dialogs are outside the page. WaveformKnob exposes a keyboard-accessible slider with pointer/wheel gestures. Per-track PCM maxima normalize cached path geometry; a centered vertical transform controls graphical amplitude inside an SVG inset5% on both vertical sides. It never changes mix gain.

VideoExporter resolves cached output IDs in main, snapshots mix, builds explicit input/output maps and spawns FFmpeg hidden with no shell. Video is copied, current mix uses volume/amix normalization disabled and FLAC/ALAC24-bit output; separate MKV audio tracks use stream copy. Metadata and chapters are copied; only the first video stream and replacement audio tracks are mapped. Per-input audio resets timestamps and pads/trims to the loaded video's reported duration for mixes/MOV. MKV raw stem tracks keep their own duration. No automatic loudness normalization, limiter, offset-probing or video fallback transcode. Existing FFmpeg discovery is local only; absence triggers a one-time user executable selection. New model dependencies are unnecessary. FFmpeg errors leave previous destination intact; unique partial outputs are removed on failure/cancel. Success atomically renames the staged file. Export locking blocks source replacement, and app shutdown terminates only its encoder. Offline tests inject fake child processes and bytes, never run actual encoders or GUI. Real sync/codec compatibility/stream parity await user testing.


## 0.6.1 native SaveVideo export (supersedes0.6.0 external process)

The local FFmpeg process implementation is removed. VideoExporter now builds an official SDK workflow: LoadVideo(file asset), chained StemStudioVideoTrack(file assets plus mix metadata), StemStudioVideo(VIDEO adapter), then the actual native SaveVideo node. SaveVideo uses flattened DynamicCombo input keys `format=mkv` and `format.codec=auto`, as verified in installed native schema/execution tests. No image-generation nodes are involved. Asset references are resolved recursively by the existing API Proxy; custom track file inputs are constrained to uploaded ComfyUI input files. Four targeted capability probes precede submission. Separating models are not run again. SDK submit/upload, polling, cancellation and output.toFile handle the complete lifecycle. Legacy proxy `images` output typing is accepted for MKV from node3 only; previews/ambiguous/empty outputs fail. Staged local publication and canonical source protection remain.

The server-side adapter implements the native VideoInput contract and is passed to SaveVideo, which owns naming, output path, metadata and PreviewVideo output. A custom adapter is required because built-in VideoFromList replacement audio uses AAC. It overrides save_to with existing PyAV: copies first video stream template/packets with timestamps, adds either original FLAC track templates/packets or24-bit FLAC encoded from a bounded float mix. Sources are interleaved with heapq by DTS/time base; audio starts at source audio stream origin, falling back to video origin. Mix length follows source video end when stream duration exists. Video decoding/re-encoding, crop/CRF overrides and arbitrary materialization are refused in this export object. Video dimensions may be inspected by native SaveVideo using normal source metadata/one-frame handling. Mix sample-rate/layout mismatch fails instead of silently resampling; same-take stems currently match. Separate raw tracks retain their lengths. Source metadata uses the same native write_output_metadata helper. Every mux/decode iteration checks Comfy cancellation; partial server output is removed after failure where possible. No subprocess, executable discovery, external runtime or new dependency.

Current mode/container UI keeps mix/separate tracks and MKV/FLAC only; MOV/ALAC is unavailable in this native lossless implementation. Recent compatible ComfyUI is required. Exact encoded payload, B-frame/AV offset, HDR/rotation and editor compatibility remain live user acceptance. Offline tests use injected SDK and fake PyAV packet/container objects, not real codecs. Existing model-download/setup behavior remains unchanged except new integration files are copied by the unified installer.


## 0.7.0 timeline layout and selection transport

The Preview routing toggle is removed; automatic source/stems routing in MediaTransport remains. Main uses ResizeObserver content height and a clamped upper-row split, with220px reserved for timeline/takes/chrome where possible. The timeline top separator changes the upper row's pixel height through a fraction of the available content height. Expanded mode changes grid placement and hides the upper row with CSS without unmounting its video; audio buffers and video reference persist. Normal split state is retained. StemTimeline exposes an expand button, resize separator and shared selection overlays. Lane/ruler selection and seek use pointerTime with full DOMRect CSS coordinates, so scrolled/zoomed geometry stays consistent. Capture-phase middle-button pan intercepts child controls and moves the scroll viewport; pointer capture and lost/cancel events clear gesture state. Range selection has no automatic edge scrolling.

MediaTransport owns normalized source-time selection and loopLocked. Snapshots include copied range values. New selection disables old lock; clearing restores full source scheduling. Lock seeks to range start, and UI starts playback when needed. Locked seek/play stay within range. While playing, RAF boundary handling seeks the video back to range start, with normal seeked/playing listeners re-aligning all AudioBufferSources; scheduled source duration is also bounded at range end. At native EOF, a locked loop restarts only while wantsPlayback remains true, so explicit pause can cancel pending restarts. Source replacement clears range; audio take changes preserve it. Offline fake video/AudioContext tests cover boundary, EOF and paused states. This does not promise sample-accurate gapless playback; browser seek, decoder and output latency are not live measured. Selection affects preview only; export graphs and native save logic are unchanged.
